# देसी टेक्कन · Desi Tekken

Tekken-style 2D fighting game in pure HTML/CSS/JS (no install, no libraries).

## VS Code mein chalao
1. Folder `desi-tekken` ko VS Code mein kholo (File > Open Folder).
2. Extension "Live Server" install karo, `index.html` par right-click > "Open with Live Server".
   (Ya seedha `index.html` par double-click karke browser mein khol sakte ho.)
3. `game.js` ke top par `CREATOR` mein apna naam likho.

## Controls
- A/D ya ←/→ : chalo (peeche jao = BLOCK)
- U = LP, I = RP, J = LK, K = RK, M = sound on/off
- Mobile par screen ke buttons

## GitHub par push
```
git init
git add .
git commit -m "Desi Tekken fighting game"
git branch -M main
git remote add origin https://github.com/<USERNAME>/desi-tekken.git
git push -u origin main
```
Pehle github.com par naya khali repo `desi-tekken` banao. Phir online khelne ke liye:
Repo > Settings > Pages > Branch: main / (root) > Save.
